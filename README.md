# Actuarial Engineering — Parallel Futures Initiative

**Repository:** `actuarial-engineering-parallel-futures`  
**Initiator:** Harsh Vikram Arora  
**Status:** Research initiative; working-paper concepts under development (October 2026).

Research at the intersection of actuarial science, stochastic risk, artificial intelligence, quantitative decision-making and the mathematics of time.

## Quick launch on GitHub Pages

1. Create a **public** GitHub repository named `actuarial-engineering-parallel-futures`.
2. Upload **all files in this folder**, especially the root `index.html`.
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, `/ (root)`, and save.
4. Visit the GitHub Pages URL displayed in Settings → Pages once deployment completes.
5. Go to **Settings → General → Features** and enable **Discussions**.
6. Optionally connect Giscus to show GitHub Discussions comments on individual website pages.

**Important:** The site intentionally does not link to a repository or Discussions URL until the owning GitHub username/organization is known and publication is complete. The footer says publication is pending; update it after launch.

## Research structure

- `PF-001` — AI-Augmented Actuarial Engineering Framework: initial working-paper concept.
- `PF-002` — Relativistic Life Insurance and Temporal Valuation: exploratory theory.
- `PF-003` — Parallel Futures Risk Engine: simulation and computational systems.
- `PF-004` — Counterfactual Underwriting and Risk Decisions: causal and decision methods.

## Scientific scope

“Parallel futures” primarily means simulated stochastic scenarios, not established evidence of physical parallel universes. The project must compare AI-supported methods against appropriate actuarial baselines and clearly report model limitations and uncertainties.
